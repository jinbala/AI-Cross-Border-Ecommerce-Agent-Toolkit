服装生意工作台 2.0 · 选品与经营整合版

一、打开软件
双击「服装生意工作台.exe」。完整保留 assets、backend 和旁边的 DLL 文件。
Windows 10/11 64 位，需要 .NET Framework 4.8 和 Microsoft Edge WebView2 Runtime。
无需另装 Python、Node.js 或浏览器插件。

二、最省事的使用顺序
1. 罗盘账号：首次在官网自行扫码登录，登录状态沿用原裤装桌面版的本机配置。
2. 选品找款：读取已有榜单，或点击立即更新，按男女裤、款型和价格找款。
   选品页展开「采集设置」即可调整范围、周期和数量，摘要显示本次最多读取条数。
   勾选「快速读榜」可跳过逐件补商品链接；需要批量补链接时关闭此项再更新。
   切换价位只筛选已保存数据，不会重启采集；想取对应价位的新榜单时再点「立即更新」。
   更新范围选「自选类目」即可勾选；点击「从已登录罗盘读取更多服装类目」，可读取本账号可见的男女装菜单，不再只局限于固定裤装类目。
   点击「初筛：成交≥100 件、转化≥3%」可先缩小范围，再调整下限和本厂擅长款关键词。
   卡片会解释条件是否匹配、哪些资料缺失；成交按原统计周期区间下限比较，仍需核实面料、工艺、起订量和本厂成本。
3. 收藏商品会保存到裤装收藏；当前页面的收藏也会同步为经营候选。
4. 在商品卡片点击「建档算利润」，会把名称、来源和链接带入产品档案并打开报价页面。
5. 填写本厂生产成本和实际供货收入，点击计算利润；罗盘价格带不会代填成工厂报价。
6. 产品档案可补面料、实测尺码、交期、品控等。AI 工作流可引用档案准备任务包和文字素材。
7. 测款记录：给新渠道设置小目标，记录真实预算、支出和收入。
8. 视频与评论（本次新增）：在左侧直接打开，可先体验服装示例。
   视频：粘贴配音稿或选择 TXT，每行一句，设置目标秒数；查看预估时长、逐句时间轴和字幕提醒。
   评论：粘贴含评分表头的表格，或选择 CSV / TSV，即可统计好中差评和已有归因；可另填卖点表看排行。
   报告可以保存到「成果资料」或导出。两项均在本机计算，不需要模型密钥，不自动生成视频或给评论分类。
   示例及其报告均标为演示；点击「清空，填自己的资料」后再录入真实资料。

三、其他选品来源
我的候选 → 添加线索：可直接写款名、链接或粘贴表格。
表格与条件初筛支持 Excel、CSV、TSV 和 8 类可调条件；资料不足保持待补。
候选的来源资料可以查看，并交给 AI 继续调研。

四、数据与升级
经营资料保存在本软件目录的 data 文件夹，建议通过「账号与设置」定期备份。
旧 1.3 版本先导出 JSON 备份，再在整合版「账号与设置」选择合并恢复。
恢复前会在 data 下自动保留一份当前经营资料备份。密钥不在备份中，需在本机设置。
罗盘的登录、收藏、采集缓存继续保留在当前 Windows 用户的 PantsSelectionWorkbench 应用数据目录。
新的经营资料与罗盘缓存分别保存，更新榜单失败或停止不会清空原榜单。
不要同时使用两个客户端切换同一罗盘账号或榜单查询；关闭一个再在另一个中更新。
程序压缩包不含经营数据、登录状态、收藏或真实采集榜单。

五、使用范围
罗盘统计周期、查询价位、榜内排名和原始区间均保留；不能把区间当作精确月销量。
本厂成本和其他渠道的结算价格、费用需要分别核实。没有自动获取 Temu 店铺数据。
AI 接口按需配置。只有点击模型生成时，才会发送当前任务和产品资料，费用按服务商计费。
模型密钥使用当前 Windows 账户加密。图片 / 视频工作流输出方案和脚本，不直接生成成品媒体。
演示数据有明确标记，仅用于试用。真实账号采集需账号本身具备罗盘权限。
