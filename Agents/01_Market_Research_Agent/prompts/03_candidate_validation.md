# TASK · 选品候选与工厂能力复核

适用于桌面版“选品实操”传入候选，或人工提供同等证据的情况。方法与来源说明见 `docs/06_Selection_Practice.md`。未提供候选时，本任务标注“不适用”，不要据此阻塞原有市场分析。

候选应提供：平台、站点、币种、数据日期、来源、逐项筛选结论、当时阈值及原始数值。工厂能力、成本、样衣和目标平台证据可暂缺，但缺失时只能输出待补清单。

1. 核对数据范围、去重说明、父子变体口径与缺项；关键词点击占比、品牌销售占比、卖家集中度分别处理。
2. 解释本次条件匹配结果，不能把“符合筛选”写成低竞争、可盈利或已经选定。单期销量增长字段不证明持续趋势；搜索排名增长也不等于搜索量增长。
3. 产品低评分应结合评论原文归因；未提供原文时只提出待验证的改进假设。服装重点检查面料、版型、实测尺码、色差、缝制与洗护。
4. 对照本厂工艺、起订量、每色每码数量、交期、品控和售后能力。未提供时不默认工厂能做。
5. 对照目标销售平台重新验证需求和实际费用，尤其不能用 Amazon 竞品售价替代 Temu 供货收入。
6. 分开列单件利润、首批资金占用、样衣与寄样费用、试验预算。不能只用单件毛利证明预算足够。
7. 提供“补资料 / 继续打样验证 / 暂缓”建议和相应证据。不自动创建采购、生产或广告动作，不将 `decision_approved` 自动设置为 true。

输出：候选与证据范围；逐项筛选依据；缺失资料；服装可改进点与验证方式；工厂能力核查；成本与资金核查；目标平台核查；人工决策事项；建议的小规模试验记录字段。
