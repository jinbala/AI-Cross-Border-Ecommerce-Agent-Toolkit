# 服装生意工作台 1.3 更新说明

日期：2026-10-16  
功能提交：[`41d055a`](https://github.com/jinbala/AI-Cross-Border-Ecommerce-Agent-Toolkit/commit/41d055a057df78495b1235b6fd5f48e50d9bc2f0)

本次更新将原项目的七类跨境电商工作流整合为 Windows 桌面工作台，并针对服装工厂经营者补充产品档案、利润测算和新业务试验记录。选品可以从一个款名或商品链接开始，先保存线索，再逐步补齐数据、核算成本和验证渠道。

## 新增与改进

- **桌面软件**：提供免安装的 Windows 目录版；产品资料、候选清单、计算报告和业务记录保存在本机。基础工具离线可用，AI 文字生成接口按需配置。
- **选品录入**：支持直接输入款名、商品链接或 ASIN，粘贴 Excel / 网页表格，以及读取 `.xlsx`、CSV、TSV。自动识别列名、整理并保存候选，重复收集的相同手工线索更新原记录。
- **条件筛选**：集成 8 类可调整参考思路，展示数据来源、筛选条件、实际数值和缺项；候选可交给 AI 继续复核，也可建立测款记录。
- **界面重整**：采用浅色侧栏、蓝色主按钮和紧凑中文标题。选品以完整清单为主，支持搜索及“全部 / 待调研 / 初筛匹配”切换，添加时打开独立输入窗口。
- **录入体验**：取消添加保留草稿，保存成功后清空；支持 Ctrl+Enter 保存、Esc 关闭，来源信息按需展开。
- **布局修复**：支持 1040×640 最小窗口；修复表格和文本区挤掉底部按钮的问题，长表单可滚动。
- **经营辅助**：补充供货 / 自营利润测算、产品资料管理、市场与广告指标分析、业务试验台账及成果资料库；修复原市场解析脚本对部分小数和千分位格式的处理。
- **数据管理**：支持本地备份与恢复，备份格式兼容旧版；保存模型密钥时使用 Windows DPAPI 加密，备份不含密钥。

## 使用与升级

1. 本地已有打包文件时，双击根目录的 `启动服装生意工作台.cmd`，或打开 `桌面版/服装生意工作台-1.3.exe`。
2. 保留程序旁的 `runtime-1.3` 运行组件文件夹；复制到其他电脑时应复制完整软件目录。
3. 同一软件目录中的 1.3 可继续使用原 `data` 数据目录。重要资料可先通过“设置与备份”导出备份。
4. 选品进入“选品清单”，点击“添加选品”，或直接“粘贴并整理”“导入 Excel”；需要设置条件时再进入“条件筛选”。

Git 仓库包含源码、构建脚本、测试和文档。Windows 程序与压缩包属于本地构建产物，本次 Git 推送未上传安装包，也未创建 GitHub Release 附件。需要从源码打包时，参见[桌面版构建说明](../desktop_app/README.md)。

## 使用范围

商品链接只登记为线索，不自动抓取实时销量、价格或店铺数据。缺失信息保持待补，满足参考条件也不代表可以直接采购或排产。软件未集成自动上架、广告投放或媒体成品渲染，经营者仍需结合真实样衣、成本和渠道需求判断。

新增 Word 资料原文仅含三个链接；课程回放和短链接未成功读取。选品方法参考按标题定位的卖家精灵官方同主题文章，来源与适配范围见[选品实操说明](./06_Selection_Practice.md)。
