# 选品实操与服装工厂复核

本流程帮助服装工厂经营者将导出的市场资料变成可追溯的候选清单，再结合本厂能力、成本与试错预算安排小规模验证。满足筛选条件只意味着值得继续检查，不代表批准选品、生产或投入资金。

## 桌面版中的使用顺序

### 简易入口（1.2 新增）

打开“选品清单”，点击“添加选品”可以输入款名、商品链接或 ASIN，再点击“整理并保存”。也可以在清单顶部直接“粘贴并整理”或“导入 Excel”。表格带上列名即可；Excel `.xlsx` 可以直接选取，程序自动寻找表头，读取首个有数据的匹配工作表，不要求先转 CSV。点击整理会自动保存，不需要逐行加入候选池。1.3 改为以清单为主的布局，支持搜索和“全部 / 待调研 / 初筛匹配”切换。

只有款式或链接时先保存为待调研线索。数据来源、市场、币种和日期都可以后补；未确认的范围不会被当作已知事实，也不会伪造销量和价格。公式只读取 Excel 保存的缓存结果，缺少缓存值时保持缺失；日期、百分比格式按单元格实际格式读取。

已识别的数据列会用于选择一个参考筛选思路；需要修改条件时再点击“条件筛选”。相同手工线索重复收集会更新原条目，已有资料与高级筛选继续保留。

### 更多条件筛选

1. 在“选品清单”打开“条件筛选”，选择一种思路。
2. 填写导出数据的平台、市场、币种和数据日期。只做手工导出文件分析，没有连接卖家精灵账号或付费 API。
3. 从有权限使用的数据工具导出 Excel / CSV / TSV。也可以下载空白模板，仅填写本次策略要求的列。
4. 导入并筛选，查看每行是“符合筛选”“资料待补”还是“不符合”，以及每一项判定依据。
5. 选择需要研究的条目加入“候选池”。保留数据来源、日期、原始数值及当时的筛选条件。
6. 在候选池中生成 AI 复核任务，补充工厂能力与成本；需要时建立测款记录。
7. 通过真实样衣和订单结果复核，再由经营者决定采购、生产或继续观察。软件不自动执行这些动作。

## 当前可执行的初筛

| 软件思路 | 需要的关键字段 | 后续重点 |
|---|---|---|
| 工厂改进机会 | 月销量、评分 | 用评论原文定位可以打样验证的质量问题 |
| 增长中的新品 | 月销量、月销量增长率、上架天数 | 核查多期变化与活动影响 |
| 新品与评价门槛 | 上架天数、评价数量 | 补充需求，避免把少评价等同于有机会 |
| 商品页面改进空间 | 月销量、LQS | 对照实拍、尺码图与产品说明 |
| 长尾需求线索 | 关键词、单词数、月搜索量 | 检查人群、场景与工厂品类是否匹配 |
| 点击分布较分散 | 点击集中度、月搜索量 | 与销量、品牌及卖家集中度分别核查 |
| 搜索排名增长线索 | 搜索排名、近一周排名增长率 | 不把排名变化当作搜索量变化 |
| 点击成本与货值 | PPC、商品均价 | 补充转化率和贡献利润再核算投放 |

上述 8 项是本项目对可核实方法的选择性实现，不是“完整复刻 26 种方法”。界面中的数值都可修改，比较边界统一使用 ≥ / ≤。长尾词的正搜索量检查、点击成本比例 5% 的初始值，以及所有工厂与预算检查，是项目的适配设计，不冒充课程给出的通用标准。

关键词单词数只对空格分词的拉丁字母词组自动计算；中文、日文等需要提供分词后的单词数，不能把字符数直接当单词数。PPC / 商品均价仅是一个单次点击与货值的比例，不是广告费用占销售额比例，也不代表利润率。

## 数据口径

- CSV 使用 UTF-8 为佳，兼容常见文本编码；支持制表符复制表格和 Excel `.xlsx`。单次最多 10000 行、15 MB；纯文字线索最多 1000 条。
- 表头支持卖家精灵常见的 ASIN、月销量（含父体列）、评分数、LQS、关键词等，以及部分英文别名。
- 缺失数据保持缺失。某项已不符合条件时整体显示“不符合”；缺项仍在依据中列出。没有已失败条件但存在缺项时显示“资料待补”。
- 百分比字段按百分点输入：`10` 或 `10%` 都是 10%；`0.1` 是 0.1%，不会自动放大到 10%。负增长是合法数据。
- 上架天数按导入时指定的数据日期与上架日期计算，不从“月份 × 30”粗算，也不使用今天替换历史快照。
- 同一表内重复 ASIN / 关键词保留首行，并显示去重数量；不自动合并父子变体，不将父体销量在多个子体上重复求和。
- 候选保存时记录源文件指纹和筛选条件；同一快照、同一条件重复保存会更新原条目，改变数据或阈值后会保留为新的候选快照。
- 不对不同币种自动换汇；PPC 与商品均价必须已经是相同币种。导入时显示的币种是你的声明，需要对照源表检查。
- Amazon 数据可用作研究线索，不能直接当作 Temu、Shopee 等其他平台的需求、售价或费用证据。

## 服装工厂复核清单

**产品问题。** 获取评论原文和实物，区分面料、版型、尺码、色差、缝制与洗护问题。低评分也可能来自物流、误解或样本过少，不能一律归为可改进的产品缺陷。

**工厂能力。** 用实际工艺、供应记录和打样结果确认是否能改进。明确每色每码起订量、补货周期、质量标准和返工成本。候选商品的参数不是我方商品的已确认参数。

**费用与现金。** 在“报价与利润”填写自己的收入、成本和承担的费用。再单独检查首批库存、样衣、寄样、履约、保证金等占款。业务试验默认预算为 0，需人工填写，不会自动批准投入。

**知识产权与真实展示。** 标杆商品用于研究需求，不直接复制品牌、图案、图片、文案或商品参数。卖家数量、跟卖数量不能证明获得品牌授权或知识产权许可。本次不实现邀评、跟卖自动化或品牌复制动作。

**执行后复盘。** 记录实际支出、收入、投入时间、质量问题和下一步。验证样衣改进与目标平台需求后再扩大；历史候选与筛选快照保留，便于解释当时为什么考虑这个款。

## 与原 Agent 的交接

`选品实操 → 01 市场分析 → 人工确认 → 02 产品策略 → 03/04/05 素材 → 业务试验 → 06/07 复盘`。

候选池交付数据平台、市场、币种、日期、原始行、策略、阈值、逐项结论和复核状态。01 Agent 继续检查工厂能力和市场证据；02 中的 `decision_approved` 仍需人工明确填写，候选“符合筛选”或标记“已验证”不会自动将它设为 true。
