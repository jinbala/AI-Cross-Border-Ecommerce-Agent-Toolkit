# 上游工具桌面接入说明

日期：2026-10-17。

首次同步原作者的 4 个提交时只合并了源码与文档，本机 EXE 及桌面入口没有更新。本次将新增视频校验、评论统计接入实际桌面程序，并完整构建后台资源。

## 软件中的入口

侧栏新增“视频与评论”，AI 工作流和数据分析页面也提供跳转按钮。视频时长与字幕、评论统计与卖点分别为两个页签，切换时保留输入和结果。修改输入会清除过期结果，计算完成后的报告可保存到成果资料或通过原生对话框导出。

配音稿支持粘贴文字与 TXT 导入，每行一句；目标时长、语速和字幕字符上限可调整。原作者的空格分词算法用于葡英稿；中文适配按汉字逐字计数、拉丁词和数字串各计一单位。自动识别不计算注释行，默认中文每秒 4 单位、葡英每秒 2.5 词。所有时长都是语速假设下的文字估算，不是实际音频测量。

评论支持粘贴 CSV / Excel 制表文本及 CSV / TSV 文件，提供评论模板、卖点模板和明确标记的服装示例。保留原作者的归因聚合和卖点权重排序，桌面适配先校验评分及频次。缺失、非有限、非整数或范围外评分不作为差评，界面披露无效行数；归因缺失保持待补。全好评或全无效评分也能给出结果，不发生除零错误。

评论工具不自动分类原文，卖点频次也来自输入表。可改进归因由使用者设置，仅作为分析口径。演示报告保留演示标记；使用清空入口或导入自有文件可开始真实分析，避免把示例卖点混进真实统计。

原作者新增的市场分析 Skill 及其他模块的 Skill 进入对应 AI 任务包，仍以服装、实际目标市场和真实资料的适配约定为优先。没有实际运行脚本或收到计算报告时，任务包不允许模型声称已完成校验。根级 Skill 用于外部 AI 工具安装，不是独立桌面按钮。

## 开发入口

- `desktop_app/upstream_tools.py`：固定上游模块加载、文字与表格校验、中文适配、临时表格归一化及结果报告。原始文件不重写。
- `desktop_app/service.py`：新增视频报告、评论报告、文件读取、示例和模板命令。
- `unified_desktop/BusinessBridge.cs`：TXT / CSV / TSV 原生选择与 CSV 模板导出。网页不得传入任意文件路径。
- `unified_desktop/business.js`：工具页签、结果展示、报告保存、输入失效处理及实际按钮验收。
- `desktop_app/core.py`：相应模块的 Skill 入口作为任务包参考。
- `unified_desktop/build.py`：完整构建包含上游脚本、Skill 及其运行依赖的后台。

文件读取限制为 3 MB，配音稿最多 1000 句，表格最多 50000 行。结果在本机计算；没有真实模型调用、商家账号操作或真实资料上传。
