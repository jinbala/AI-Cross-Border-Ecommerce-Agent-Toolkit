服装生意工作台 1.3
==================

一、启动
双击「服装生意工作台-1.3.exe」。无需安装 Python、Excel 或其他开发环境。
保留程序旁的 runtime-1.3 文件夹，它包含运行组件。请不要只复制单个 EXE。
请放在当前 Windows 账户有写入权限的普通文件夹，不要放到 Program Files。

二、第一次使用
1. 产品档案：新建一个真实款式，填写面料、尺码、交期与生产成本，点击保存。
2. 报价与利润：关联产品，选择供货或零售，填写实际费用并计算。
3. AI 工作流：选择七类任务之一，关联产品，填目标市场与补充资料，生成任务包。
4. 没有模型接口：复制任务包到你常用的聊天工具，把结果粘贴回「文字结果」并保存。
5. 已有模型接口：到设置填写兼容 Chat Completions 的接口地址、模型名称和密钥，保存后返回工作流生成。
6. 业务试验：记录渠道、预算、实际支出、收入和结果，逐步验证新业务。
7. 选品清单：复制 Excel / 网页表格后点击“粘贴并整理”，或者点“导入 Excel”。带列名即可，无需改成模板或 CSV。
8. 候选池：生成 AI 复核任务或建立测款记录，再结合本厂能力、样衣与实际成本验证。

更省事的开始方式：
进入“选品清单”，点击“添加选品”，输入“亚麻衬衫”或粘贴商品链接，每行一个，再点“整理并保存”。
取消添加会保留草稿，下次继续；成功保存后会清空输入框。也支持 Ctrl+Enter 保存，Esc 关闭。
在清单顶部搜索款式或 ASIN，或切换“全部 / 待调研 / 初筛匹配”。选中一款后在下方查看资料并继续 AI 调研。
软件先自动保存待调研清单，不要求先填齐销量、评分、站点和币种。
有表格时自动识别列名并保存；需要调整条件时再进入“条件筛选”。
表格复制请带表头；Excel 直接支持 .xlsx，旧版 .xls 可复制内容粘贴。
读取首个能识别出表头且有数据的工作表，显示所用的工作表名称。公式只读缓存值，不重算。

三、主要功能
- 本地产品档案，真实面料、尺码表、包装、售后和交期。
- 供货 / 自营利润测算，盈亏报价、目标报价与批量测算。
- 七类原项目工作流：市场、产品策略、文案、图片策划、视频脚本、广告、评论。
- 查看各模块说明、原案例与交付检查清单。
- CSV / TSV 市场指标分析；广告 CTR、CVR、CPC、CPA、ROAS 速算。
- 业务试验台账、CSV 导出、成果资料库、Markdown 导出。
- 本地备份与恢复。
- 8 类选品初筛、数据缺项检查、候选池及可追溯筛选依据。

四、数据与密钥
软件的 data 文件夹保存数据库；不要删除它。
移动到另一台电脑时，复制整个软件文件夹（含 runtime-1.3 和 data），或先在「设置与备份」导出备份。
1.3 与旧版共用程序目录的 data 数据。新备份包含候选池，也能恢复旧版备份。
备份不包含模型密钥。勾选保存密钥时，使用 Windows DPAPI 加密，绑定当前 Windows 账户。
生成 AI 内容时，当前产品和任务资料会发送到你配置的服务商，费用按服务商计费。
普通使用、离线计算、复制任务包与本地保存不需要模型密钥。

五、使用边界
图片 / 视频模块输出制作方案、提示词和脚本，未集成媒体渲染服务。
没有自动拉取店铺数据、上架、投广告、发消息和自动排产功能。
原项目主要参考 Shopee / Mercado Livre；Temu、供货等场景提供通用资料辅助。
所有平台规则与费率需要按自己后台和合同核对。
财务结果按输入测算，业务台账现金收支不等于会计净利润。
示例用于学习格式，不能当作你的真实商品、市场或收益数据。
选品模块处理人工导出资料，没有连接卖家精灵账号或付费 API。筛选条件仅是研究起点。
链接只登记为线索，不会自动取得实时销量或价格。资料不足的保持待调研，不产生盈利结论。
新增 Word 文档为链接目录，课程回放未读取；实际参考同主题官方文章，来源说明在选品实操页面。

六、故障
如遇操作错误，查看 data/error.log；启动错误查看 data/startup_error.log。
更换模型时填写服务商提供的真实地址和模型名称；本软件不会自动创建或购买模型账号。
