# 裤装选品工作台 · Windows 桌面版

双击桌面的“裤装选品工作台”或 `PantsWorkbench.exe` 即可使用。客户端内可自行登录罗盘、保存商品榜、按男女裤和价格筛选、搜索、收藏并导出。日常使用无需 Node.js、VS Code、浏览器插件或连接授权。需要 Windows 10/11 64 位、.NET Framework 4.8 和 Microsoft Edge WebView2 Runtime；当前电脑已检测到这些环境。

左侧四个入口分别是“选品工作台”“我的收藏”“罗盘账号”“更新设置”，不再混用登录、页面刷新和本地刷新按钮。

1. 首次进入“罗盘账号”，在客户端中的罗盘官网自行扫码登录。之后通常保留登录状态；失效时重新扫码，登录完成后继续待更新的任务。
2. 打开客户端先显示已有商品，默认后台更新一次；也可随时点击主界面的“立即更新”。自动选择类目、统计周期、价位，翻页并补取商品链接，全部成功后一次性保存。
3. 在“选品工作台”多选价位或输入自定义区间，已有结果立即筛选；价格变化停止约一秒后，后台补取相应价位。新结果自动显示，保留搜索、裤型、价格条件与收藏。连续修改价格时以最后选择为准。
4. “更新设置”可选择常用两类、全部女裤、全部男裤或全部裤装，统计近 1／7／30 天，每类每个查询价位前 10／20／50／200 款；也可关闭启动时自动更新。默认是女装牛仔裤、男装休闲裤各前 10 款。

价格带按罗盘页面原值显示。商品标题与“打开商品”按钮均可点击，地址在浏览器中打开。当前 20 条已逐个点击罗盘官方商品名称，补齐实际弹出的商品地址；不能仅凭“查看详情”按钮不可用判断标题入口也不可用。

价格筛选在主界面：0–50、50–70、70–99、99–150、150 元以上可同时选择；自定义示例 `80-120；180-250`，多段用分号分隔，满足任意区间且价格带有交集即入选，同款只显示一次。可保存常用组合，下次直接选择。单段上下限和 SKU 价格依据收在可选设置中；价格未知仍保留并提示，价格带不会被改写为 SKU 最低价。

客户端价位逐段查询。罗盘各类目的推荐价位不同，客户端优先点击匹配的价位；没有匹配项时使用官网“自定义”填写上下限，提交后重新打开核对数值，再关闭弹窗读取榜单。官网自定义边界按罗盘口径执行，卡片与导出标注“自定义”。切换类目时等待新榜单与价位加载，不沿用旧类目的选项。

多段自定义区间按覆盖它的客户端价位取榜，再按精确区间筛选，例如 80–120 元会读取 70–99 与 99–150 两段。读取数量上限针对每个类目、每个查询价位，未代表精确自定义区间内所有商品；卡片和报告保留查询价位，排名对应原查询条件。

安装到当前电脑：在项目根目录双击 `安装桌面版.cmd`。会创建桌面和开始菜单快捷方式，不需要管理员权限，不设置开机自启。

应用安装在本机 LocalAppData 下的 `PantsSelectionWorkbench/App`；登录状态和收藏保存在相邻的 `UserData`，采集记录保存在 `Data/compass-data.json`。重新安装不会删除这些数据。普通浏览器与客户端的登录和收藏分别保存。账号密码、验证码和扫码操作都在罗盘官网进行，程序不读取普通 Edge 的登录数据。

工具优先显示你在客户端采集的榜单；尚未采集时显示内置的两类首页共 20 条真实试采，周期为 2026-10-06 至 2026-10-12。只包含已经保存的页，未代表完整 TOP200。已保存结果可离线查看；登录和读取罗盘需要联网及账号本身具备的权限。

更新进度直接显示在选品主界面。采集失败、页面变化或主动停止时，上次保存的榜单保留；仅当平台明确显示“暂无数据”等空榜状态时保存零结果。项目更新页面后，客户端会加载新界面，并继续优先显示你在客户端自行采集的榜单。罗盘页的“保存当前页”保留为可选的手动采集入口。

下载清单或表格时会弹出保存位置选择框。CSV 商品 ID 列请按文本导入表格软件，以免长数字丢失精度。导出的视图不等于原始导入模板。

构建：`powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build_desktop.ps1`。首次构建从微软 NuGet 包下载固定 SDK 版本 1.0.2903.40，产物在 `dist/desktop`，压缩包在 `dist/裤装选品桌面版.zip`。压缩包包含当前已保存榜单，可以解压后运行；它不会自动关联其他电脑的项目目录。

桌面宿主使用微软 WebView2；罗盘和登录窗口在客户端内打开，商品链接在普通浏览器打开。采集只读取已呈现的页面和实际标题跳转，不调用私有接口。远程页面没有本机文件读写桥接。应用专属登录数据和自行采集的记录不随程序压缩包导出。

开发验证：`PantsWorkbench.exe --smoke-test 输出路径.json` 使用独立测试存储，验证真实页面渲染、男女裤切换、下载按钮、本地存储及 CSV 实际保存，并输出页面截图后退出。

`PantsWorkbench.exe --collector-smoke-test 输出路径.json` 在隔离测试环境中使用内嵌夹具，验证本页采集、实际弹窗事件获取链接、同页更新、文件保存与恢复、读取失败保留旧数据。该测试不登录真实账号，不代表已验证具体账号的登录和权限。

`PantsWorkbench.exe --update-smoke-test 输出路径.json` 验证自动选类目、翻页、分价位查询、空榜、链接获取、同款去重、保留筛选、设置导航和停止后保留旧文件，使用隔离的模拟官网夹具，不会覆盖正式收藏和采集数据。

`PantsWorkbench.exe --login-smoke-test 输出路径.json` 在隔离环境中打开真实官网登录页，保存可见页面状态及截图后退出；`--open-compass` 可直接启动到客户端罗盘页。扫码后的账号权限和真实榜单读取需要本人首次登录后验证。
